# About Hexstrike-N.O.V.A. (Project OMEGA)

## The Vision
Hexstrike-N.O.V.A. is the culmination of project-wide synchronization, designed to provide elite offensive capabilities directly to the operator's pocket. It solves the critical bottleneck of "Simulation-Debt"—the gap between tool availability and tool accessibility—by providing a unified, AI-augmented interface for the world's most powerful red-team utilities.

## Core Architectural Pillars

### 1. Hexstrike-Boaz Central Orchestrator
The backbone of the ecosystem. This FastAPI-driven hub transforms the operator's host machine into a high-performance offensive node. It manages the lifecycle of all tools, handles LLM reasoning bridges, and ensures that every CLI command executed via the mobile app is optimized for the target environment.

### 2. The N.O.V.A. Intelligence Engine
N.O.V.A. is more than an assistant; it is a **Neural Offensive Virtual Assistant**. It is trained on the Spartan-7 adversarial dataset and optimized for edge-inference. By using **Gemma 4 E2B QAT**, N.O.V.A. can provide complex network strategies, payload recommendations, and OSINT analysis without ever touching the public internet.

### 3. Dynamic Arsenal GUI (DAG)
The GUI is no longer a static form. It is a dynamic wrapper that auto-generates interfaces based on tool metadata. This allows for:
*   **Zero-Config Tooling:** New tools added to the `~/arsenal` are instantly mappable to the UI.
*   **Command Sync:** What you see in the GUI is exactly what executes in the terminal.
*   **Expert Overrides:** Integrated command reference lists provide presets while maintaining the flexibility of raw manual CLI input.

Hexstrike-N.O.V.A. adheres to the **"Zero-Trace"** protocol. By leveraging local LLMs and secure RPC tunnels, operator footprint is minimized.
